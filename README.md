# PF-LAB-TASKS

A comprehensive collection of Programming Fundamentals (PF) lab tasks, assignments, and practice problems implemented in C and C++.

**Institution:** FAST-NUCES  
**Course:** Programming Fundamentals

### 📚 Topics Covered
* **Basics & Control Structures:** Data Types, Variables, Operators, Expressions, If-Else, and Switch statements
* **Loops:** For loops, While loops, and Do-While loops
* **Functions & Recursion:** Pass by Value/Reference, and Recursive functions
* **Arrays & Strings:** 1D/2D Arrays and String Manipulation
* **Pointers:** Pointer Arithmetic and Double Pointers
* **Dynamic Memory Allocation (DMA):** `malloc`, `calloc`, `realloc`, and `free`
* **File Handling:** Reading and Writing Text and Binary Files
* **Advanced Concepts:** Bitwise Operators, Macros, and Preprocessor Directives
